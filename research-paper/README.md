# To Buffer or Not to Buffer — channel capacity in Go

Research paper + full experimental artifact. Every number in the paper was
produced by the code in this directory on this machine; nothing is invented.

## Layout

- `paper/main.tex`, `paper/main.pdf` — the paper (LaTeX, compiled with tectonic)
- `paper/figs/` — figures (generated by `analysis/plots.py`)
- `paper/gen/tables.tex` — generated tables (do not edit; regenerate)
- `autobuf/` — the `autobuf` library (`AutoSize`)
- `bench/` — characterization harness
- `tuner/` — tuner-vs-oracle evaluation command
- `results/` — raw CSV data + `summary.json`
- `analysis/plots.py` — figures, tables, digest

## Reproduce

```bash
go build -o bin/bench ./bench && go build -o bin/tuner ./tuner

# characterization sweep (~8 min, 220 runs)
for p in 1x1 1x4 4x1 4x4; do
  for b in 0 1 2 4 8 16 32 64 128 256 512; do
    for t in 1 2 3 4 5; do
      ./bin/bench -pattern $p -buf $b -csv results/bench.csv -tag r$t
    done
  done
done

# pointer-channel sweep, 4x4 only (~2 min)
for b in 0 1 2 4 8 16 32 64 128 256 512; do
  for t in 1 2 3 4 5; do
    ./bin/bench -pattern 4x4 -buf $b -ptr -csv results/bench_ptr.csv -tag r$t
  done
done

# tuner evaluation (~4 min)
./bin/tuner -patterns 1x1,1x4,4x1,4x4 -eval-trials 10 -csv results/tuner.csv

# analysis -> figures, tables, summary.json
python3 analysis/plots.py       # or .venv/bin/python (has matplotlib)

# paper
tectonic paper/main.tex
```

## Library usage

```go
import "autobuf/autobuf"

best, scores := autobuf.AutoSize(autobuf.Config{
    Candidates: []int{0, 1, 2, 4, 8, 16, 32, 64, 128, 256, 512},
    Warmup:     150 * time.Millisecond,
    Measure:    350 * time.Millisecond,
}, func(b int) float64 {
    // build a short-lived probe of YOUR real pipeline around
    // make(chan T, b), measure it, and return throughput.
    return probeThroughput(b)
})
ch := make(chan T, best)
```

Headline results (16-core x86-64, Fedora 43, Go 1.26.10, n=5):
unbuffered costs 40–92% of achievable throughput; throughput saturates by
capacity 32–64; p99 latency grows ≈1 hand-off-interval per buffer slot under
sender oversubscription; the tuner is within −0.1%…+2.1% of the best capacity.
